# MVISION

Aplikasi manajemen sekolah (KB, TK, SD, SMP).

- `index.html` — demo simulasi (data fiktif, tanpa server). Tampil di https://masginanjar.github.io/mvision/
- `web/` — aplikasi sungguhan tahap 1 (React + Vite + Tailwind + Supabase). Tampil di https://masginanjar.github.io/mvision/app/
- `supabase/migrations/` — skema database dan aturan hak akses (RLS).
- `docs/ATURAN-PROYEK.md` — aturan tetap proyek (mobile-first, siap Android/iOS).

Cabang `gh-pages` berisi hasil jadi: demo di akar dan aplikasi di `app/`.
